FN 组合键

连接

FN+1 / 2 / 3蓝牙通道 1 / 2 / 3仅蓝牙档有效；长按约 3 秒重新配对
FN+42.4G 对码 / 回连长按约 3 秒；仅 2.4G 档有效

布局与锁定

FN+A切换 Windows 布局默认布局；按模式分别保存
FN+S切换 macOS 布局Alt 与 Win 键功能互换；按模式分别保存
FN+WWASD 与方向键互换再次按下恢复，设置掉电保存
FN+Win锁定 / 解锁 Win 键仅 Windows 布局；掉电不保存
FN+F11全键盘锁定 / 解锁仅 Windows 布局；再次按下解锁
FN+Esc恢复出厂设置长按约 2 秒

多媒体

FN+F1打开媒体播放器
FN+F2 / F3音量 − / 音量 +
FN+F4静音
FN+F5 / F7上一曲 / 下一曲
FN+F6播放 / 暂停
FN+F8停止播放
FN+F9打开邮件
FN+F10打开“我的电脑”
FN+F12打开计算器

灯效

FN+Ins循环切换灯效 1 → 13
FN+ScrLk灯效开 / 关
FN+↑ / ↓亮度增加 / 降低
FN+← / →灯效速度降低 / 提高
