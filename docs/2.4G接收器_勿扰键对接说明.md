# 2.4G 接收器：Mac 勿扰键（F6）对接说明

键盘在 Mac 布局下按 F6，USB 和蓝牙模式直接发送 Generic Desktop `0x9B`（System Do Not Disturb），Mac 收到后切换勿扰（专注）模式，无需任何系统设置。

勿扰在 macOS 上**只能**用 Generic Desktop 页的 `0x9B` 发送，Consumer（多媒体）页没有对应的用法（见苹果《Accessory Design Guidelines》第 14.1 节表 14-3、表 14-4），所以没法借用接收器现有的多媒体报告。

2.4G 模式下 Mac 只和接收器通信，需要接收器把键盘发来的值放进它自己的 System Control 报告转发给 Mac。**键盘这一侧已经实现，本文说明接收器需要做的修改。**

## 1. 键盘发出的 RF 数据包

格式与多媒体键包相同，长度 `iRF_K_LENGTH_OTHER`（3 字节），加密包类型为 `PACKET_TYPE_FOR_OTHERS`。

| 字节 | 值 | 说明 |
|---|---|---|
| 0 | `0x80` | `iRF_K_TYPE_KB` |
| 1 | `0x40` | `iRF_K_OTHER_SYS`（系统键包） |
| 2 | 用法值 | Generic Desktop 用法 ID：按下勿扰为 `0x9B`，释放为 `0x00` |

第 2 字节和键盘 USB / 蓝牙 System Control 报告里的用法值**完全相同**，接收器不需要做转换。

发送时机：
- **按下 F6**：发 `0x9B`；**松开**：发 `0x00`。每次状态变化连发 8 包。
- **按住不放**：每约 64 个发送周期补发 2 包（保活），内容与当前状态相同。

接收器应按"状态"处理：只在值变化时向电脑发送报告，重复包忽略。

## 2. 接收器需要修改的地方

### 2.1 USB 报告描述符新增 System Control 集合

使用和键盘 USB / 蓝牙相同的格式（与 QMK `host_system_send()` 一致，已在 macOS 上验证可切换勿扰）。`<ID>` 换成接收器里未被占用的报告 ID：

```
05 01        Usage Page (Generic Desktop)
09 80        Usage (System Control)
A1 01        Collection (Application)
85 <ID>        Report ID (<ID>)
19 01          Usage Minimum (0x01)
29 B7          Usage Maximum (0xB7)
15 01          Logical Minimum (1)
26 B7 00       Logical Maximum (0xB7)
95 01          Report Count (1)
75 10          Report Size (16)
81 00          Input (Data, Array, Absolute)
C0           End Collection
```

### 2.2 收到系统键包时发送报告

把第 2 字节原样作为 16 位用法值的低字节：

| 收到的第 2 字节 | 发给电脑的报告 |
|---|---|
| `0x9B` | `[<ID>, 0x9B, 0x00]`（勿扰按下） |
| `0x00` | `[<ID>, 0x00, 0x00]`（释放） |

## 3. 现有接收器的实测结果

用现有接收器测试时，键盘已经按第 1 节发送 `[0x80, 0x40, 0x9B]`：按 F6 **没有任何反应**，也没有误触发电源或睡眠。所以：
- 现有接收器不转发系统键包，需要按第 2 节升级接收器固件；
- 升级之前，2.4G 下按 F6 没有作用，但不会造成任何副作用。USB、蓝牙下不受影响。
